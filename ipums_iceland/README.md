The data is contained in the .dat and .xml files. To process it, you must first run the main file, which generates CSV tables from the original data. 

From the newly obtained CSV tables, run the preparacao.py file, which prepares the data for running the models by splitting it into training, testing, and validation sets.

Finally, to run the models, simply run the ml_homonimo.py file.

The final metrics were obtained from the metricas.py, media_desvio.py, heuristica.py, teste_hipotese.py, and testes.py files.
